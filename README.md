# 推荐一个VPN代理工具

如果你需要一个支持多平台使用的外网加速服务，可以试试 [NTHU.CC / Net Thunder Access](https://nthu.cc/#/register?code=QaOnKLNd)

它提供 Windows、macOS、Android、iOS 多端使用方案，支持官方客户端、Clash、Shadowrocket 等常见工具；后台也有“我的订阅”和“一键订阅”功能，安装客户端后可以快速导入配置并开始使用。

比较适合需要稳定访问外网学术资源、日常跨境网络服务，或者希望在多设备上统一配置代理订阅的用户。

## 推荐理由

- 支持 Windows、macOS、Android、iOS 多平台
- 提供官方客户端和 Clash / Shadowrocket 等常见客户端教程
- 后台支持一键订阅，配置相对方便
- 可先试用，再根据需求购买套餐
- 官方文档包含软件下载、注册和客户端使用说明
